# PhotoTable v.0.2

Приложение помогает собрать фотографии на листах для печати и добавить к снимкам подписи.

## Возможности

- Добавление нескольких фото кнопкой «+ Добавить фото», выбором папки или перетаскиванием в окно.
- Миниатюра и поле подписи для каждого снимка.
- Перемещение снимков вверх/вниз, удаление выбранного снимка и очистка списка.
- До 8 фотографий на листе: 4 в верхнем ряду и 4 в нижнем. Порядок — слева направо, сверху вниз.
- Подсчёт числа листов, индикатор обработки и кнопка открытия папки результата.
- Подпись можно оставить пустой. Поддерживаются JPG, PNG, BMP, TIFF и WebP.

## Запуск приложения из исходников

Нужен Python 3.10 или новее с поддержкой Tkinter.

```bat
python -m pip install -r requirements.txt
python app.py
```

В Windows приложение можно запустить двойным щелчком по `start.bat` после установки зависимостей.

## Сборка установщика Windows

Нужны Python 3.10+ и установленный Inno Setup 6. Файл `build_installer.bat`:

1. Создаёт виртуальное окружение `.build_venv`.
2. Устанавливает зависимости из `requirements-build.txt` (включая PyInstaller 6.22.3).
3. Собирает приложение в папку `dist\PhotoTable` с помощью PyInstaller.
4. Создаёт установщик `dist\PhotoTable_v0.2_Setup.exe` с помощью Inno Setup Compiler.

Чтобы собрать установщик:

1. Установите [Inno Setup 6](https://jrsoftware.org/isinfo.php). Если `ISCC.exe` не добавлен в `PATH`, скрипт ищет его в стандартных системных и пользовательских папках установки.
2. Дважды щёлкните `build_installer.bat`.

Зависимости приложения указаны в `requirements.txt`, сборочные зависимости — в `requirements-build.txt`. Для упаковки drag-and-drop компонентов используется PyInstaller hook `hook-tkinterdnd2.py`. Промежуточные файлы создаются в `build` и `dist` и исключены из Git.

Установщик ставит программу в `%LOCALAPPDATA%\Programs\PhotoTable`, создаёт ярлык в меню «Пуск» и предлагает ярлык на рабочем столе. Установленному приложению не нужен отдельный Python.

## Папка с результатами

По умолчанию листы сохраняются в `%USERPROFILE%\Pictures\PhotoTable\PhotoTable_ГГГГММДД_ЧЧММСС`. Папку назначения можно изменить в интерфейсе. Каждый лист сохраняется в JPEG-файл вида `photo_table_01.jpg`.

Шаблон печати и шрифт находятся в `static\card.jpg` и `static\arial.ttf`.
