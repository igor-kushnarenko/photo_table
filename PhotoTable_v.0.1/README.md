# PhotoTable v.0.1

Приложение помогает собрать фотографии на листах для печати и добавить к каждой фотографии подпись.

## Возможности

- Добавление нескольких фотографий через кнопку «+ Добавить фото» или целой папки.
- Перетаскивание файлов в окно (после установки зависимостей из `requirements.txt`).
- Миниатюры и поле подписи для каждого снимка.
- Изменение порядка фотографий кнопками ↑ и ↓, удаление отдельных снимков и очистка списка.
- Предварительный подсчёт количества листов: на одном листе размещается до 8 фотографий, слева направо и сверху вниз.
- Сохранение результата в отдельную папку запуска и открытие этой папки из приложения.

Поддерживаются JPG, PNG, BMP, TIFF и WebP. Подпись можно оставить пустой.

## Запуск

Нужен Python 3.10 или новее с поддержкой Tkinter.

```bash
python -m pip install -r requirements.txt
python app.py
```

В Windows приложение также можно запустить двойным щелчком по `start.bat`.

Если пакет `tkinterdnd2` не установлен, приложение всё равно запускается: фотографии можно выбрать кнопкой или добавить папкой.

## Результаты

По умолчанию листы сохраняются в `output/PhotoTable_ГГГГММДД_ЧЧММСС/` рядом с приложением. Папку назначения можно изменить в окне. Каждый лист сохраняется как JPEG `photo_table_01.jpg`, `photo_table_02.jpg` и так далее.

Для раскладки используются шаблон `static/card.jpg` и шрифт `static/arial.ttf`. Сохраняйте их рядом с `app.py` в папке `static`.
